WebSocket++

2.0.0-dev

Fork and continuation of the original (now mostly inactive) websocketpp project. The goal of this fork is to modernize and evolve the library while providing a straightforward upgrade path for existing users. We are AI-positive.

WebSocket++ is a header-only C++ library that implements RFC 6455, the WebSocket protocol. It allows integrating WebSocket client and server functionality into C++ programs. It uses interchangeable network transport modules based on raw buffers, C++ iostreams, or Asio (standalone or Boost). Custom transport policies can support other networking and event libraries.

Features

  • RFC 6455 (WebSocket version 13)
  • Message and event based interface
  • Secure WebSockets (TLS), IPv6, and proxies
  • Standalone Asio and Boost.Asio
  • Interchangeable transport modules
  • Portable across POSIX and Windows
  • C++11 or later
  • Thread-safe

Getting started

Clone the repository and add its root directory to your project’s include path.

git clone https://github.com/GreenLightning/websocketpp2.git

CMake

For a checkout in external/websocketpp2:

add_subdirectory(external/websocketpp2)
target_link_libraries(my_program PRIVATE websocketpp::websocketpp)

For an installed package, replace add_subdirectory() with find_package(websocketpp CONFIG REQUIRED). The target supplies the headers and C++11 requirement. Applications select and link their own transport dependencies.

Existing users should read the upgrade notes for changes to standard-library types, error types, and Asio APIs.

Requirements

A C++11 compiler and standard library. The Asio transport additionally needs one of the following backends. TLS requires OpenSSL.

BackendMinimum versionSelection
Standalone Asio1.12.0Define ASIO_STANDALONE
Boost.AsioBoost 1.66.0Leave ASIO_STANDALONE undefined

Define ASIO_STANDALONE consistently across all translation units. With it defined, raw and iostream transports need neither Asio nor Boost. CMake integration requires CMake 3.18 or later.

Continuous integration builds and tests with GCC, Clang, and MSVC, standalone Asio, and the oldest supported dependencies.

Example: echo server

This server listens on port 9002 and echoes each message to its sender.

#include <websocketpp/config/asio_no_tls.hpp>
#include <websocketpp/server.hpp>
#include <iostream>

using server = websocketpp::server<websocketpp::config::asio>;

int main() {
    server echo;
    echo.set_message_handler(
        [&echo](websocketpp::connection_hdl hdl,
                server::message_ptr msg) {
            echo.send(hdl, msg->get_payload(), msg->get_opcode());
        });
    echo.init_asio();
    echo.listen(9002);
    echo.start_accept([](websocketpp::lib::error_code const &ec,
                         websocketpp::lib::error_code const &transport_ec) {
        std::cout << "Accept loop ended: " << ec.message() << "/"
                  << transport_ec.message() << std::endl;
    });
    echo.run();
}

Try it with the browser client. Use ws://localhost:9002 from a locally opened client, or a trusted wss:// endpoint when using the client over HTTPS.

More programs are in the examples directory. The tutorials explain the broadcast and chat examples step by step.
