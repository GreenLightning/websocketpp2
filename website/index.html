WebSocket++

A header only C++ library that implements RFC 6455, the WebSocket protocol.

Getting started Manual API reference GitHub

WebSocket++ allows integrating WebSocket client and server functionality into C++ programs. This is a fork and continuation of the original (now mostly inactive) websocketpp project. The goal is to modernize and evolve the library while providing a straightforward upgrade path for existing users.

Features

  • Full support for RFC 6455 (WebSocket version 13)
  • Message/event based interface
  • Secure WebSockets (TLS), IPv6 and explicit proxies
  • Interchangeable network transport modules (raw, iostream, Asio, or custom)
  • Works with standalone Asio and with Boost.Asio
  • Portable (Posix/Windows) and thread-safe

Example

An echo server that listens on port 9002:

#include <websocketpp/config/asio_no_tls.hpp>
#include <websocketpp/server.hpp>

typedef websocketpp::server<websocketpp::config::asio> server;

int main() {
    server echo;
    echo.set_message_handler([&echo](websocketpp::connection_hdl hdl, server::message_ptr msg) {
        echo.send(hdl, msg->get_payload(), msg->get_opcode());
    });
    echo.init_asio();
    echo.listen(9002);
    echo.start_accept();
    echo.run();
}

To talk to it, open the browser client and connect to ws://localhost:9002. More programs are in the examples directory, and two of them are explained step by step in the tutorials.

Requirements

A C++11 compiler and standard library. The Asio transport additionally needs one of the following (the iostream and raw transports need neither):

BackendSelectionMinimum version
Standalone AsioDefine ASIO_STANDALONEAsio 1.12.0
Boost.AsioLeave ASIO_STANDALONE undefinedBoost 1.66.0

These minimum versions, GCC, Clang and MSVC are built and tested on every change by GitHub Actions.

Using it with CMake

find_package(websocketpp CONFIG REQUIRED)
target_link_libraries(my_program PRIVATE websocketpp::websocketpp)

The target supplies the headers and the C++11 requirement. Applications select and link their own transport dependencies.
